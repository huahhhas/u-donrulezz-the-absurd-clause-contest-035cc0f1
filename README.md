# The Absurd Clause Contest

One line, buried deep in the terms of service: an absurd clause, written deadpan, that quietly turns strange.

> Clause 14.7: by clicking Accept, you grant us a perpetual, royalty-free licence to your shadow, which we may lend to third parties on overcast days without further notice.

`main.py` (Python standard library only) writes the clause to `/output/entry.txt` and prints it. Run it with `python3 main.py`.
